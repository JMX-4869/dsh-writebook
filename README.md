# dsh-writebook

DeepSeek Harness（DSH）的写书插件：把工作区里的 `books/` 目录变成侧边栏里的一个面板，
写、读、改、记经验都在里面，agent 也能通过 `writebook` 工具读到「现在在写哪本」。

## 装

```bash
# 用 plugin_manager 安装本地目录
plugin_manager { action: "install_bundle", target: "<这个目录的绝对路径>" }
```

装完重启 DSH，侧边栏会出现书本图标，设置页也会多一页「写书」。

## 功能

| 位置 | 干什么 |
|---|---|
| 侧边栏「写书」 | 书架 → 书（目录 / 设定）→ 章节 |
| 书架 | 多本书，各自的章数 / 字数 / 更新时间；「设为当前」标记正在写的那本 |
| 书页 | 目录（章节 + 字数）、设定（`01_世界观.md` 这类） |
| 阅读页 | 正文 / 设定，可编辑；**空闲 1.2 秒自动保存** |
| 写作经验 | 跨书通用的踩坑记录，按写作环节分组，可新增 |
| 章节页顶部 | 「前情」（上一章结尾）+「这一章」（伏笔表里该埋 / 该收的） |
| 章节页「记一笔」 | 边写边记一行，落进 `procedures/_inbox.md` |
| agent 工具 `writebook` | `current` / `list` / `set`——写书前先问一句现在是哪本 |

## 目录约定

```
<工作区>/
  books/
    故拟/
      书.json              { "书名": "...", "类型": "...", "一句话": "..." }
      01_世界观.md         设定（文件名以数字开头就认）
      02_人物.md
      05_伏笔表.md         表格：| # | 伏笔 | 埋在哪 | 收在哪 | 收的时候改变什么 |
      正文/
        第001章_疤.md       正文（文件名带 第N章 就按数字排）
       .backups/           自动生成的备份，不进目录
  procedures/              写作经验卡（跟 dsh-mood 的经验卡同一套格式）
    _inbox.md              边写边记的一行式
    写书-xxx.md            成型的卡
  .writebook.json          当前在写哪本
```

## 保存与备份

- 编辑态空闲 1.2 秒自动落盘；「保存」只是立刻做同一件事
- 保存前比对 mtime：这期间文件被别人（或 agent）改过会**拒绝覆盖**，提示刷新
- 每次内容真变了才备份；同一文件留 **1 个现用文件 + 3 个最近版本**（`.backups/`），第 4 份进来删最旧的

## 已知限制

- 面板只管写小说：`procedures/` 里不带 `写书-` 前缀的卡不进这个面板
- 备份没有恢复入口，要退版本得手动从 `.backups/` 拷回去
- 章节页的「这一章」只认 `05_伏笔表.md` 的表格格式，表改了要跟着改解析
