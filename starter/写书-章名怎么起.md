# 章名太直白或者太虚

> **症状**：觉醒、第一次死亡、孤独的求生者
> **场景**：结构
> **来源**：给DeepSeek_故拟写作指导（Claude 写的）· 2026-10-25 第六部分第 6-8 条
> **对账**：`node tools/note.mjs --sync`　这条现在还犯不犯，跑一下就知道

## 解法
章名是读者在目录里看的第一眼，也是读完"咔哒一声对上"的那一下。

**八条规矩**
1. 取自本章里真实出现过的东西：物件、数字、动作、原话。不用概括出来的"主题"
2. 1—7 字最好，最长不超过 10
3. **不剧透本章最后一个画面或反转**
4. 不用抽象词：命运、真相、觉醒、孤独、秘密、救赎、恐惧
5. 不用"XX之XX""致XX"，不用感叹号，不用比喻
6. 不泄露全书真相：AI、前代、试验体、系统在监控，一概不许出现
7. 同一卷里句式换着来，不要连续三章都是单个名词
8. 可以和章末最后一句呼应，但一卷里不超过两章

**十种取名法**
物件 / 短动作 / 已发生的事 / 原话 / 数字 / 缺失 / 账本上那句人话 / 术语反讽 / 玩家黑话 / 回声（母题）/ 系统文案体【】

**一章里同一种不超过三分之一。**

## 例子
| 章名 | 问题 |
|---|---|
| 觉醒 | 抽象词 |
| 第一次死亡 | 像情节摘要 |
| 他发现自己没有影子！ | 感叹号 + 提前说了反转 |

✅ 疤 / 十步 / 影子 / 报时的 / 不组 / 太整齐了
