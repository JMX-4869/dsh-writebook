# 别拿别人的文风指纹当标准

> **症状**：觉得自己写得"碎"或"寡淡"，于是去抄一份"好文风指标"（短句占比、句长、感叹号密度），照着改
> **场景**：语言
> **来源**：读《写书管线训练数据.md》（2026-10-25）+ 《故拟》三章实测
> **对账**：`node tools/note.mjs --sync`　这条现在还犯不犯，跑一下就知道

## 那份数据是什么

一个会话抽了《妖武乱世》《两界修仙》两本书的量化指纹，当作"好文风"：

| 维度 | 它给的"好" |
|---|---|
| 短句（≤12字） | **23.8%** |
| 平均句长 | 27.55 字 |
| 对话行占比 | 32% |
| 感叹号 | 7.62/千字 |
| 省略号 | 11.56/千字 |

## 套到《故拟》上，全部不成立

| | 《故拟》 | 差距 |
|---|---|---|
| 短句 | **44–45%** | 近两倍 |
| 句长 | 15 字 | 一半 |
| 对话行 | 2–11% | 三分之一 |
| 感叹号 | **0** | 一个没有 |
| 省略号 | 0–1.4/千字 | 几乎不用 |

**照着改会怎样：**

- 补感叹号 → 破掉"系统提示不带语气"的设定
- 补省略号 → 破掉"不写犹豫"的冷叙事
- 拉长句到 27.5 → 变成另一种书
- 对话赶到 32% → 这本书前三章只有半步仙一个活人，硬凑就是注水

## 判据

**指纹要从这本书自己身上抽，不能拿别人的当尺子。**

同一份文档还说：**GLM 系怎么钉提示词都压不住"碎短句"（38–42%）**。

**而《故拟》的短句是 45%。**

它比"被判定为病的碎"还碎。这说明两件事：

1. **"碎"不是绝对病**——如果那本书要的就是碎，45% 就是对的
2. **但这种书给 GLM 写，会碎到 38–42% 之外**——因为模型会顺着提示词的调子走，再碎一点

## 那这本书到底碎不碎

**这个问题的答案不在比值，在读完的感受。**

我实测三章：

- 极短段落（≤10字）占 29–41%
- **但其中一半是【系统提示】**（面板、经验、死亡提示），必须独立
- 剩下的"一句一段"只有一成多，而且都是节拍：`没做梦。` `不等了。` `不追人。`

**结构上是"长段 + 单句节拍"交替，不是全碎。**

**真正的碎感来自"相邻两句都短"**——那是句子长度分布的事，不是段落的事。

## 什么时候不适用

- **如果是新书第一次定调**：这时候确实该参考别人的指纹，因为你还没有自己的
- **如果读者反馈"读不动/像电报"**：那说明当前这本书的短句确实过头了，该往回调
- **但调的方式是"这本书自己前后对比"**（前三章 vs 第十章），不是跟别人的书比
