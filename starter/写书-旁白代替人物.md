# 旁白代替人物 —— 不是 A 是 B / 他感到 / 他意识到

> **症状**：情绪刚冒头，旁白先否定它；或者直接报"他感到紧张"
> **场景**：文字
> **来源**：《故拟》三章 + Claude 版对照 · 2026-10-25
> **对账**：`node tools/note.mjs --sync`　这条现在还犯不犯，跑一下就知道

## 解法
**"不是 A，是 B"**：整章最多 1—2 处，而且只在 A 和 B 是两个真实存在的不同东西时用。

**"感到 / 觉得 / 意识到"**：写"那儿有什么"，不写"他感觉到什么"。

## 例子
✅ 允许：不是戳在空气里那种空，是连空气都没有。
✅ 允许：不是慢慢暗下去的，是像有人关了灯。
❌ 该删：不是翻属性，是找那个地方。

## 为什么
情绪刚冒头就被旁白否定，读者感觉人物在"压抑感情"，久了就觉得他是木头。

## 什么时候不适用
人物自己在推理、在算账的时候，"意识到"可以用——那是他的动作，不是旁白替他说。
